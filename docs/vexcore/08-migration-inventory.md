## First Migration Candidate

The safest first runtime migration after Foundation 1.0 is:

```text
Authentication contract
→ identity resolver adapter parity tests
→ permission evaluator parity tests
→ web admin route guard pilot
```

Do not start with admin repositories or venue management repositories. They are too broad and tenant-sensitive until identity and permission context is stable.
